# LynxPrompt

LynxPrompt is a self-hostable platform for managing AI IDE configuration files: `AGENTS.md`, `.cursor/rules/`, `CLAUDE.md`, slash commands, and 30+ other formats. Run it on your own infrastructure and your team gets one place to create, share and standardize AI coding assistant configs across every project. A hosted instance runs at [lynxprompt.com](https://lynxprompt.com).
